## Liste des thèmes 

| Date | Nom | Description | **Idée** |
| :--- | :--- | :--- | --- |

| **02-11-2026** | Lignes | Un classique du défi cartographique. Une carte avec des lignes. | Le réseau de chemin de fer en France |
| **03-11-2026** | Polygones | Un classique du défi cartographique. Une carte avec des polygones. | Les grandes régions productrice de vins AOP en France |
| **04-11-2026** | Regroupements (Clusters) | Des regroupements de quelque chose. Points chauds, groupes, éléments qui se rassemblent. |  |
| **05-11-2026** | Sens : La vue | Comment voyez-vous quelque chose ? Pourquoi pas cartographier un champ de vision (*viewshed*) ? |  |
| **06-11-2026** | Vintage | Activez votre machine à remonter le temps et réalisez une carte d'apparence historique, ou thématisée vintage. |  |
| **07-11-2026** | Carte en 10 minutes | Vous n'avez pas plus de 10 minutes pour réaliser cette carte. |  |
| **08-11-2026** | Utopie | Une carte de quelque chose qui pourrait être. | Population en 2050 ? |
| **09-11-2026** | Urbain-rural | Urbain ou rural. Villes et campagne. |  |
| **10-11-2026** | Uniquement par instructions | Pour cette carte, faites travailler l'IA et produisez quelque chose du début à la fin dans une fenêtre de chat ou en ligne de commande. |  |
| **11-11-2026** | Sens : L'ouïe | Comment entendez-vous quelque chose ? Comment cartographier un paysage sonore ? Une carte de la pollution sonore ? |  |
| **12-11-2026** | Puissance | Puissance nucléaire ? Ou force physique / influence ? Un réseau électrique sur une carte ? Interprétez ce thème comme vous le souhaitez, comme pour chaque défi. |  |
| **13-11-2026** | Interactions | Interactions entre les éléments, ou peut-être que le résultat sera une carte interactive ? |  |
| **14-11-2026** | Carte borgésienne | Une carte si détaillée qu'elle en devient le territoire. Inspiré de la nouvelle de Borges *De la rigueur de la science*. |  |
| **15-11-2026** | Dessus-dessous | À l'envers, sens dessus dessous. Quelque chose sur cette carte ne tourne pas tout à fait rond. |  |
| **16-11-2026** | Carte collaborative | Réalisez une carte avec un ami, un collègue ou un inconnu. L'IA ne compte pas comme un ami :) |  |
| **17-11-2026** | Ombre et lumière | Jouez avec les effets visuels. Que pouvez-vous cartographier avec seulement de la lumière et des ombres ? |  |
| **18-11-2026** | NULL | Valeur nulle / rien. |  |
| **19-11-2026** | Sens : L'odorat | Comment cartographier ce que votre nez peut percevoir ? À quoi ressemble une carte qui "sent" ? |  |
| **20-11-2026** | Hexagones | Les hexagones, ces bons vieux "bestagons". |  |
| **21-11-2026** | OpenStreetMap | La formidable source de données pour la cartographie. Vous pouvez aussi utiliser cette journée pour modifier OSM. |  |
| **22-11-2026** | Projections | Les différentes manières de représenter un globe sur une surface plane. Qu'est-ce que votre projection cartographique préférée dit de vous ? |  |
| **23-11-2026** | Sens : Le goût | Nourriture, boisson ou autre chose que l'on peut goûter. |  |
| **24-11-2026** | Réseau | Réseau routier, réseau de transport en commun, réseau humain ou quelque chose de complètement différent. | Les antenes 5G en France |
| **25-11-2026** | Est-ce une carte ? | Repoussez les limites des cartes et mélangez votre carte avec une œuvre d'art ou une visualisation de données créative. Quand est-ce qu'une chose devient une carte, et quand cesse-t-elle de l'être ? |  |
| **26-11-2026** | Eau | Environ 71 % de la surface de la Terre. Cette chose mouillée, vous voyez ? |  |
| **27-11-2026** | Nouvel outil | Le défi a toujours été d'apprendre des choses. Essayez un nouvel outil dans votre flux de travail cartographique. |  |
| **28-11-2026** | Sens : Le toucher / Les sensations | Le plus abstrait de la série des sens. Comment cartographier un sentiment ou une sensation ? |  |
| **29-11-2026** | Raster | Faites quelque chose de sympa avec des pixels. |  |
| **30-11-2026** | Stylo et papier | Il est temps de conclure le défi en fermant votre ordinateur portable pendant un moment et en revenant aux sources. Réalisez une carte analogique avec un stylo et du papier. |  |
